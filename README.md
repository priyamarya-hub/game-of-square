# 🎮 Game of Square

A simple interactive web project created while learning **HTML, CSS, and JavaScript**.


## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🎯 Features

* **Square 1:** Generates a random number when the mouse enters.
* **Square 2:** Changes its background color on mouse hover.
* **Square 3:** Generates a random RGB color on mouse hover.
* **Square 4:** Changes the colors of the other squares when clicked.

## 📚 What I Learned

While building this project, I practiced:

* HTML structure
* CSS Flexbox
* JavaScript DOM manipulation
* `getElementById()`
* `addEventListener()`
* Mouse events
* Click events
* `Math.random()`
* Changing CSS using JavaScript
* Template literals

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Move your mouse over the squares and click Square 4 to interact with the game.
